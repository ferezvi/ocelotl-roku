# Ocelotl Branding

## About

Ocelotl Roku is a customized Jellyfin Roku experience focused on design, typography and user interface improvements.

It is based on the official Jellyfin Roku client, which remains the recommended choice for users who prefer the original experience.

## Philosophy

Ocelotl focuses on:
- A refined visual experience
- Better typography and readability
- Custom themes
- Subtitle rendering improvements
- Roku-native performance

## Colors

Primary: #7C3AED
Background:#0E0323

## Name

Ocelotl means jaguar in Nahuatl, representing speed, strength and precision.
